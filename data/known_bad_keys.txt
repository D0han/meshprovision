# IMPORTANT, READ THIS BEFORE ASSUMING THIS FILE PROTECTS YOU FROM CVE-2025-52464:
#
# This file does NOT contain the keypairs affected by CVE-2025-52464 ("Repeated
# Public/Private Keypairs", CVSS 9.5, Meshtastic firmware >=2.5.0 <2.6.11).
# No such list has ever been published. This was verified during planning by
# enumerating the complete file trees of meshtastic/firmware and
# meshtastic/Meshtastic-Android and by reading NodeDB.cpp and CryptoEngine.cpp at

# key"), and the advisory itself publishes no blocklist. Publishing one would
# also mean publishing live private keys for nodes still in the field.
# Padding this file with invented entries would give false assurance, so it is
# deliberately short and honest.
#
# The effective controls against CVE-2025-52464 in meshprovision are:
#   * the firmware-version window check  (crypto/weakkeys.py, WeakKeyCheck.FIRMWARE_WINDOW)
#   * cross-node duplicate detection across your own Keys sheet (WeakKeyCheck.DUPLICATE)

# degenerate. These same 7 values are also compiled into
# crypto/weakkeys.py:SMALL_ORDER_POINTS, so they apply even when this file is absent.
